# InstrumentScripts

Instrument control and acquisition scripts.

- `keithley6485/` — Keithley 6485 picoammeter via PyVISA.
- `usb6001/` — NI USB-6001, dual amplified thermocouple inputs (AI0 + AI1); CLI, logging, and plotting.
- `examples/` — stand-alone examples.

See [`usb6001/README.md`](usb6001/README.md) for setup, wiring, and commands.
